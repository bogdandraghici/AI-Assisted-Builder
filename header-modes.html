Header modes — Build vs Admin

The complaint: the mode toggle sits far right, but what it changes is dead centre — cause and effect are strangers. Worse, Build/Admin and Config/Runtime wear the same segmented-control clothes, the left side stays project-scoped while the centre jumps to platform scope, and the only trace of which world you're in is one small highlight. Eight answers below, each live — click the mode controls and watch what moves.
