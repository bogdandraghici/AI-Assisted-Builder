The complaint: the mode toggle sits far right, but what it changes is dead centre — cause and effect are strangers. Worse, Build/Admin and Config/Runtime wear the same segmented-control clothes, the left side stays project-scoped while the centre jumps to platform scope, and the only trace of which world you're in is one small highlight. Round 2 — Admin is not an errand

Corrected model: in Build the agent drives; in Admin you drive — the existing heavy manual workspace, which brings its own navigation below the header and is not this prototype's subject. The header owes Admin exactly one thing: the Config/Runtime switch. No rails, no sheets, no subheaders. The spine (mark · env · project · branch · Share) holds everywhere; the open question is where that one switch lives and how loudly the mode speaks.

M8 · The switch unfoldsAdmin's only furniture is Config/Runtime, so it lives inside the switch itself — selecting Admin unfolds the two options in place. Cause and effect are the same control; the centre just empties, nothing teleports.
