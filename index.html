01 The plan takes shape, and gets argued with

Eight minutes into a new project. The agent proposed five steps, built the two that needed no discussion, and is now refusing to remove a third — its argument is a drawing, not a canvas. Plan language throughout, and no resource is named until you ask. Click step 3 — it opens in place.

02 The same screen, with that step open

Not a second screen — the one above, already opened, so both states sit on this page at once. The plan has folded into a spine and the conversation has held its place, so settling a step never costs you the argument that produced it. On the right: what the agent will build, then three decisions — one still open, one the builder answered, one they handed back — then the numbers the agent chose on its own. Every identifier is behind one disclosure at the bottom. Close it with the ×, with Esc, with the breadcrumb or with the back arrow.

Loading the step…

03 The same screen again, running what exists

Two of five steps are built, so this run cannot finish — which makes the edge, not the preview, the subject. The check you asked to drop was built at 09:37, two minutes before you objected, so the run goes straight through it: unseen, three seconds, never in the customer's way. Then it stops, and the tool draws over the app to say so — in the dark palette, because white is the thing you built and dark is the thing that built it. Which is why Agree is here, on the step you have just watched run. Press Test what exists on either frame above and the plan lies down into this one.

Loading the run…

04 The same run, scrubbed back to the first step

A run reads left to right, so the plan lies down beneath the app and the boundary becomes a wall across its path. The strip is the scrubber and the blue edge follows it, now on the first node. Only the three steps that ran can be looked at; the last two cannot, because nothing of them exists to show. The app's one live control is whatever the run's next move was, so the screen offers exactly what the run offered: one way on, or none.

Loading the run…

05 The same run, with the app filling the screen

The chat is the one thing in this prototype that never moves, and this is its single exception — you have asked to see only the app, so the tool gets out of the way. The frame goes from 1032 × 491 to 1392 × 804 on the same 340ms curve the plan collapses on, and the strip goes with the chat, which takes Agree out of reach on purpose: it is one keystroke away, not hidden. Back via the same control in the same slot, or Esc.
